The Teams Bot lets you chat with ClippyClaw from the Microsoft Teams app on any device - phone, tablet, or web browser. Messages are relayed through a cloud server to your running ClippyClaw desktop instance, which processes them with full access to your tools and skills. ClippyClaw desktop must be running and connected for Teams messages to be answered.
