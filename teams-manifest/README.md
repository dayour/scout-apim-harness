# Teams Bot Manifest

This directory contains the Microsoft Teams app manifest for the Microsoft Scout bot.

## Files

- `manifest.json` — Teams app manifest (v1.17)
- `color.png` — 192x192 full-color icon, generated from `public/icon.svg` (transparent Scout comet, no background)
- `outline.png` — 32x32 monochrome icon, generated from `public/scout-icon-monochrome.svg` as pure white on transparent (per Teams spec)

## How the zip is built

The individual manifest files are bundled into the Electron app as `extraResources`. The ZIP is created on-the-fly at runtime when the user selects "Download manifest" in the Integrations panel — see `electron/zip-manifest.ts`.

## Updating icons

Both PNGs are generated by `pnpm generate:icons` (`scripts/generate-badge-icons.mjs`) — rerun it after the source SVGs change.

`color.png` is generated from `public/icon.svg`. Sourcing from the SVG keeps the background transparent so Teams' rounded avatar mask doesn't show a white squircle, and the comet is inset with transparent padding (`TEAMS_ICON_CONTENT_RATIO` in `scripts/generate-badge-icons.mjs`) so its corners aren't clipped by the mask and it reads at the same scale as other Teams app icons.

`outline.png` is the icon Teams shows in the left app bar (rail). It is generated from `public/scout-icon-monochrome.svg` as **pure white (#FFFFFF) on transparent**. Teams uses only the alpha channel and auto-tints the shape to the active theme — light on dark themes, dark on light themes. The white source is required: a baked-in dark fill defeats the tint and the icon renders dark on both themes, disappearing on the dark rail. The ZIP is rebuilt automatically at download time.

## Sideloading in Teams

1. From the Teams sidebar, select **Apps** > **Manage your apps** > **Upload an app**.
2. Select **Upload a custom app**.
3. Select the app package .zip file, `scout-bot.zip`, then select **Add**.

## Azure Bot Portal (required for mobile icon)

The bot icon in Teams **desktop** comes from the manifest `color.png`. However, the **mobile** bot avatar is controlled by the Azure Bot Channel Registration, not the manifest. Without this step, Teams mobile shows the default bot icon.

To update the bot icon in Azure:

1. Sign in to the [Azure Portal](https://portal.azure.com).
2. Navigate to **Azure Bot** (search "Bot" in the top search bar).
3. Select the Microsoft Scout bot resource (App ID: `00000000-0000-0000-0000-000000000000`).
4. In the sidebar under **Configuration**, select **Settings**.
5. Under **Bot profile**, select the existing icon or the upload area.
6. Upload `color.png` (192x192 mascot) as the bot's messaging icon.
7. Select **Apply** or **Save** to save the icon.

Changes may take a few minutes to propagate to Teams mobile clients.
